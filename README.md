# Hapooie Telegram Bot

ربات تلگرامی هاپویی همراه با سیستم سطح‌بندی (XP)، کازینو ایموجی‌محور، ماهیگیری، و سیستم قاچاق سگ و زندان.

## دستورات و سطح دسترسی
- **سطح ۱:** `/start` یا `هاپویی` / `آکادمی هاپویی` / `پروفایل هاپویی` / `هاپ` / `ماهیگیری` / `فروش ماهی`
- **سطح ۲:** `بانک هاپویی`
- **سطح ۳:** `کازینو هاپویی` (تاس زوج/فرد 🎲 و اسلات 🎰 با شرط‌بندی سفارشی مثل `50k` یا `50;000`)
- **سطح ۴:** `انبار ماهی` / `قاچاق هاپویی` (همراه با دستگیری، جریمه، زندان ۱۵ یا ۳۰ دقیقه‌ای و فرار ۵۰٪)
